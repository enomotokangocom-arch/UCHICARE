## 1. 現行評価表の課題

現行の `erg1`〜`erg8` は「従業員本人が4段階で自己回答し、合計点を良好/要改善/要注意に区分する」アンケートです。現地訪問の評価として使うには、次の課題があります。

### 1-1. 抽象的・主観的な項目

| 元項目 | 抽象的な部分 | 問題点 |
|---|---|---|
| erg1 椅子や机の高さは、使う人の体格に合っている | 「体格に合っている」 | 何を見れば「合っている」のかの基準がない。調整機能の有無・調整されているか・共用か、が区別されていない |
| erg2 モニターや書類の位置は目線の高さに近く… | 「目線の高さに近く」「無理な首の角度」 | 観察可能だが基準が回答者の感覚に依存。ノートPC単体・複数画面・書類参照などの条件が抜けている |
| erg3 頻繁に使う物品は無理なく手が届く範囲に | 「無理なく」「頻繁に」 | 頻度・リーチ距離・高さ(床置き/棚上段)が特定されない |
| erg4 同一姿勢が長時間(1時間以上)続かないよう、作業の工夫がされている | 「作業の工夫がされている」 | 工夫の中身(ローテーション、小休止の仕組み等)が問われず、あるか無いかの印象回答になる |
| erg5 十分な明るさ・換気・室温 | 「十分な」 | 照明・換気・温熱の3要素が1問に混在し、どれが問題か特定できない。測定や記録との対応がない |
| erg6 台車・リフトなどの補助具が使える環境である | 「使える環境」 | 「置いてある」と「実際に使われている」が区別されない。使われない理由(遠い・狭い・時間がない)が拾えない |
| erg7 床は滑りにくく、つまずく障害物がない | 2要素の混在 | 滑り・段差・配線・置き物・濡れが1問にまとまっており、場所が特定できない |
| erg8 作業姿勢や身体の使い方について、会社から指導や情報提供を受けている | 「指導を受けている」 | 受けた記憶の有無を問うため、個人の記憶・関心に左右される。教育の内容・頻度・対象は分からない |

### 1-2. 個人評価になりやすい項目

- **形式全体**: 従業員一人ひとりの自己回答を合計してスコア化するため、結果が「その人の感じ方・知識・我慢強さ」の評価に近くなります。同じ職場でも回答者により点がぶれ、作業や設備の課題としての特定が難しくなります。
- **erg8(指導を受けている)**: 「受けていない」と答えた人が「聞いていなかった人」と読まれやすく、個人の責任に帰着しやすい項目です。
- **erg1・erg2**: 「自分の体格に合っていない」という回答は、個人の体格の問題と誤解されやすく、本来の論点(調整機能・調整の運用)が見えなくなります。
- **結果メッセージ**: 「要注意」「療法士による個別評価をおすすめします」は、個人のリスク判定のように読めます。
- **関連調査票との重複**: 同アプリの腰痛リスク調査 `bp4`(現在、腰痛がある)は健康情報そのもので、作業環境評価と混ぜると個人の健康状態の収集・推定につながります。本再設計では作業環境評価に健康情報を含めません。

### 1-3. 現地訪問の評価として不足している視点

1. **評価単位の記録がない**: どの部門・どの作業・どの場所・どの時間帯を見たのか、何人・何サイクル観察したのかが記録されない。
2. **ばく露(頻度・時間・人数)の視点がない**: 「ある/ない」だけで、その負担が1日に何回・何分・何人に生じるかが分からず、優先順位を付けられない。
3. **評価領域の欠落**: 反復動作・手腕の力、押す・引く、作業ペース・人員、繁忙時、認知的負担(割り込み・情報量・手順の分かりやすさ)、組織的条件(報告・応援・改善提案)、騒音、暑熱、職種特有のリスクがない。
4. **根拠欄がない**: 観察した事実、設備・書類の確認結果、聞き取り内容を残す欄がなく、評価者間で判断を比較・検証できない。
5. **「該当なし」「未確認」が区別できない**: 例えば重量物を扱わない部門で erg6 に答えると、低評価と混ざる。
6. **重大な安全上の懸念が合計点に埋もれる**: 転落・挟まれ・熱中症のおそれなど、緊急性の高い事項を別扱いする仕組みがない。
7. **法令上の義務と推奨の区別がない**: 例えば照度・室温・暑熱対策には法令上の規定がある一方、多くの項目は推奨事項であり、企業に伝える際の重みが異なる。

### 1-4. 改善提案・企業への報告に不足している情報

- 改善の対象(どの作業・どの場所・何人)
- 改善策の種類(すぐできる/設備投資/業務設計の見直し)と実施負担
- 担当者・期限・効果確認の指標・再評価時期
- 企業側に判断してもらう事項(予算・人員配置・優先順位の決定)
- 評価の限界(観察した時間帯・作業に限られること、医学的判断ではないこと)
- 部門ごとの「強み」(維持すべき良い取り組み)

## 2. 評価の実施要領

### 2-1. 評価の目的と対象

- **目的**: 部門・作業工程・代表的な作業について、作業内容・作業環境・設備や道具・作業時間と休憩・業務の進め方を確認し、身体的・認知的な負担や安全上の課題を見つけ、企業が実行できる改善策につなげること。
- **評価しないもの**: 従業員個人の能力・努力・健康状態・性格・ストレス耐性。医学的診断や疾病リスクの判定。
- **評価単位**: 「部門 × 代表作業 × 場所 × 時間帯」を1単位(以下「評価単位」)とし、評価表は評価単位ごとに1枚作成する。
- **観察対象者**: 作業そのものを見るために作業者を観察するが、記録は作業と条件についてのみ行い、氏名は記録しない。

### 2-2. 訪問前に企業へ確認する情報(事前シート)

訪問の1〜2週間前に、担当窓口(人事・総務・安全衛生担当など)へ依頼します。提出できないものは「未提出」で構いません。

| 区分 | 確認する情報 | 用途 |
|---|---|---|
| 組織 | 部門一覧、部門ごとの人数規模(概数)、勤務形態(シフト・夜勤・テレワークの有無) | 評価単位の選定 |
| 作業 | 部門ごとの主な作業と、負担が大きいと担当者が考える作業(3つ程度) | 代表作業の候補 |
| 時間 | 始業・終業・休憩時間、繁忙な曜日・時間帯・季節 | 訪問日時の設定 |
| 設備 | 主な設備・補助具・福祉用具の一覧と配置図(あれば) | 設備確認の準備 |
| 記録(集計値のみ) | 過去1〜3年の労働災害・ヒヤリハットの件数と作業別の内訳(個人名は不要) | 重点作業の把握 |
| 体制 | 衛生委員会・安全衛生委員会の有無と開催状況、産業医・衛生管理者等の選任状況、改善提案の仕組み | 組織的条件の確認 |
| 既存の取り組み | 作業手順書、教育資料、過去の職場巡視記録、環境測定記録(照度・温湿度・WBGT・騒音など)の有無 | 根拠資料 |
| 訪問条件 | 撮影の可否と条件、立入制限区域、保護具の要否、聞き取りに協力できる人数と時間 | 当日の段取り |

※ 健康診断結果、個人の受診歴・疾病情報、ストレスチェックの個人結果は依頼しません。

### 2-3. 当日の進め方(標準:半日)

| 時間目安 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:20 | 開始時打合せ(管理者・窓口) | 目的が個人評価でないことを説明。評価単位・観察ルート・撮影可否を確定。管理者ヒアリング(第4章 M1〜M4)の一部 |
| 0:20〜2:20 | 評価単位ごとの現場観察(1単位 30〜45分 × 2〜3単位) | ①全体を見渡す(5分)→②代表作業を数サイクル観察(15〜20分)→③設備・環境の確認と測定(5〜10分)→④従業員への短い聞き取り(5〜10分) |
| 2:20〜2:50 | 記録確認 | 手順書・教育記録・ヒヤリハット集計・環境測定記録などを確認 |
| 2:50〜3:20 | 評価者による整理 | 評価の確定、重大懸念の有無、すぐできる改善の候補を整理(評価者が2名なら突き合わせ) |
| 3:20〜3:40 | 終了時の口頭報告 | 重大懸念は当日中に口頭で伝える。強み・暫定の優先課題を共有。正式報告は後日 |

**訪問時間別の実施範囲**

| 区分 | 時間 | 実施範囲 |
|---|---|---|
| 短時間版 | 約90分 | 1部門・1〜2作業。評価表の「短時間版★」項目のみ。ヒアリングは管理者1名+従業員2〜3名(各5分) |
| 標準版 | 半日(3〜4時間) | 2〜3部門・各1〜2作業。標準項目すべて(該当なしを除く)+該当する職種別項目 |
| 詳細版 | 1日 | 4部門以上、または繁忙時間帯と通常時間帯の両方を観察。職種別項目を含めた全項目、必要な環境測定 |

### 2-4. 部門・代表作業の選び方

次の観点で候補を挙げ、事前打合せで企業と合意して選びます。全従業員への一律評価は行いません。

1. **負担が大きいと思われる作業**: 企業担当者・現場責任者が「大変」「人が定着しにくい」「ヒヤリハットが多い」と挙げる作業。
2. **従事者が多い作業**: 1つ改善すると多くの人に効果が及ぶ作業。
3. **時間が長い作業**: 1日の作業時間の大半を占める作業(例:入力作業、ピッキング、ライン作業、介助)。
4. **労災・ヒヤリハットの集計で目立つ作業**。
5. **条件の違い**: 同じ作業でも、繁忙時間帯/通常時間帯、日勤/夜勤、新人が多い時間帯で負担が変わる場合は、どちらを見たかを明記する(可能なら両方)。

**観察数の目安**(評価者間のぶれを減らすための最低限の目安で、統計的な基準ではありません)

- 周期のある作業(ライン・ピッキング等):同じ作業を3サイクル以上、可能なら2名以上の作業者で観察。
- 周期のない作業(事務・介護・営業等):10〜15分以上の連続観察と、聞き取りによる1日の流れの確認。
- 観察数・観察時間は必ず「訪問記録ヘッダー」に記録する。

### 2-5. 観察・聞き取り・記録確認の方法

**観察**
- 「事実」を書く:例「段ボール(表示重量12kg)を床置きパレットから腰の高さの台へ、前屈しながら1時間に約40箱移す」。「姿勢が悪い」のような評価語は根拠欄に書かない。
- 頻度・時間を数える:1サイクルの時間、1時間あたりの回数、連続時間をストップウォッチや時計で確認する。
- 対象範囲を書く:その作業に従事する人数(概数)、勤務帯。
- 撮影:企業の許可がある場合のみ。顔が映らない角度・手元中心で撮る。報告書に使う写真はぼかし等の処理をする。
- 測定(機器がある場合):照度計、温湿度計、WBGT計、騒音計、メジャー、重量計(はかり)。測定値は場所・時刻・条件とともに記録。機器がない場合は企業の測定記録を確認するか「未確認」とする。

**聞き取り**
- 1人5分以内、作業の手を止めすぎない時間帯に行う。
- 質問は作業・環境・進め方についてのみ(第4章)。症状・病歴・服薬・家庭事情は聞かない。従業員が自分から話した場合も、記録には残さず「作業に関連する負担の訴えあり」程度にとどめる。
- 回答は「誰が言ったか」ではなく「何人中何人が同様の内容を述べた」で記録する。

**記録・資料確認**
- 手順書・掲示物・教育記録・点検記録・環境測定記録・ヒヤリハット集計・委員会議事録(該当議題)などを確認し、「あり/なし/最終更新日」を記録する。
- 資料は写しを持ち帰らず、確認した事実のみメモする(企業の許可がある場合を除く)。

### 2-6. 評価尺度と判断の手順

| 評価 | 記号 | 定義 | 記録上のルール |
|---|---|---|---|
| 良好 | ◎ | 判断基準の「良好」を満たす。維持すべき取り組みとして報告書の「強み」に使える | 良好の根拠となる事実を1つ以上書く |
| 一部改善 | ○ | 概ね対策されているが、一部の場所・時間帯・作業者で基準を満たさない。または対策はあるが運用が徹底していない | どこが不足しているかを書く |
| 要改善 | △ | 判断基準の「要改善」に該当する。負担や危険が日常的に生じている | 事実+頻度・時間・対象範囲を書く |
| 優先対応 | ! | 重大なけが・健康障害につながるおそれがあり、早期の対応が必要(下記「重大懸念」の例に該当) | 評価表に加えて**重大懸念記録**へ転記し、当日中に口頭で伝える |
| 該当なし | — | その評価単位にその作業・設備・環境がない(例:重量物を扱わない事務作業) | 該当しない理由を一言書く。集計から除外 |
| 未確認 | ? | 該当する可能性はあるが、時間・立入制限・資料未提出等で確認できなかった | 確認できなかった理由と、次回の確認方法を書く。集計から除外し、報告書に一覧で示す |

**重大懸念(「優先対応」)に該当する例** ― 総合評価とは別に必ず示します。
- 墜落・転落、挟まれ・巻き込まれ、重量物の落下などのおそれがある状態が放置されている
- 暑熱環境の作業で、報告体制や悪化防止の手順が定められていない(法令上の義務に関わる)
- 介護・看護の移乗で、福祉用具が使えない状況での人力の抱え上げが日常的に行われている
- 非常口・避難通路・消火設備の前が物でふさがれている
- 従業員から、けがにつながりかけた事象が繰り返し語られ、対策が取られていない

**評価者間のぶれを減らすための約束事**
1. 判断は「事実 → 判断基準の文言 → 評価」の順で行い、根拠欄に事実がない評価は付けない。
2. 迷ったら低い方に付けるのではなく、「一部改善」か「要改善」かを**頻度・時間・対象範囲**で決める(例:一部の人が一時的に行う → 一部改善、作業者の多くが毎日繰り返す → 要改善)。
3. 見ていないものは「未確認」とし、推測で評価しない。聞き取りだけで判断した場合は確認方法欄に「聞き取りのみ」と明記する。
4. 評価者が2名の場合は、別々に記入してから突き合わせ、異なった項目と理由を記録する。初回導入時は、同じ写真・動画で評価を練習してから訪問する。
5. 法令・指針に数値がある項目以外は、評価表で数値の合否判定をしない(数値は事実として記録する)。

### 2-7. 改善の優先順位の付け方

単純な合計点では判断しません。「要改善」「優先対応」になった項目ごとに、次の3要素を確認して優先順位を付けます。

| 要素 | 大 | 中 | 小 |
|---|---|---|---|
| 重大性(起こりうる結果) | 重いけが・休業につながるおそれ、法令上の義務に関わる | 痛み・疲労の蓄積、作業ミス・手戻りにつながる | 不便・不快にとどまる |
| ばく露(頻度・時間) | 作業時間の大半、または毎日何度も繰り返す | 毎日あるが一部の時間 | 週に数回以下・繁忙時のみ |
| 対象範囲(人数) | 部門の多くの作業者 | 特定の班・シフト | 少数(1〜2名程度の担当業務) |

- **優先度1(すぐ対応)**: 重大懸念に該当するもの。または重大性「大」で、ばく露か対象範囲のどちらかが「大」。
- **優先度2(3か月以内に着手)**: 重大性「大」の残り、または重大性「中」で、ばく露・対象範囲のどちらかが「大」。
- **優先度3(半年〜1年で計画)**: 上記以外の「要改善」。
- **維持・継続**: 「良好」「一部改善」で、運用の徹底や定期点検で足りるもの。

さらに改善策を「すぐできる改善(低コスト・現場で決められる)」と「検討を要する改善(設備投資・人員配置・業務設計)」に分け、同じ優先度なら、すぐできる改善から着手することを提案します。

### 2-8. 個人情報・健康情報の扱い

- 収集しない:氏名、社員番号、健康診断結果、症状・疾病・服薬、ストレスチェック個人結果、家庭事情。
- 聞き取りの記録は人数単位(例:「4名中3名が…」)。少人数部門(目安として5名未満)では、発言内容から個人が推測されないよう、部門をまとめて記載するか表現を一般化する。
- 写真は顔・名札・画面の個人情報が映らないようにし、企業との取り決めに従って保管・削除する。
- 報告書は部門・作業単位で記述し、「Aさんの姿勢が悪い」のような個人を特定・非難する表現を用いない。
- 評価結果を人事評価や個人の配置判断の資料に使わないことを、事前に企業と合意しておく。

### 2-9. 評価の限界と、別途専門家への相談が必要なケース

**限界**
- 訪問日・時間帯・観察した作業の範囲での評価であり、季節・繁忙・欠員などで状態は変わる。
- 観察・短い聞き取りに基づく定性的評価で、作業負担を定量的に測定したものではない。
- 医学的診断、個人の健康状態の判定、疾病リスクの判定は行わない。
- 法令の適合性を網羅的に判定するものではない(法令に関わる項目は「確認の必要あり」として示す)。

**別途専門家への相談を勧めるケース**
| 状況 | 相談先の例 |
|---|---|
| 作業に関連した痛み・体調不良の訴えが複数の従業員から出ている、または休業者が出ている | 産業医、地域産業保健センター(従業員50人未満の事業場) |
| 重量物・反復作業について、負担を定量的に評価して設備や作業設計を決めたい | 人間工学の専門家、労働衛生コンサルタント |
| 騒音・暑熱・有害物質・粉じん等の測定や対策が必要 | 作業環境測定機関、労働衛生コンサルタント |
| 機械の安全(挟まれ・巻き込まれ)に懸念がある | 機械安全の専門家、労働安全コンサルタント、設備メーカー |
| 介護・看護の移乗方法や福祉用具の選定 | 理学療法士・作業療法士、福祉用具専門相談員 |
| 長時間労働・人間関係・ハラスメント等の訴えが聞かれた | 産業医、産業保健スタッフ、社内相談窓口(評価者は内容に立ち入らず、窓口につなぐ) |

### 3-4. 集計の仕方(評価単位ごと・部門ごと)

## 5. 改善優先順位とアクションプラン

### 5-1. 作成手順

1. 評価表で「!」「△」になった項目を抜き出す(「○」は運用改善としてまとめて扱う)。
2. 2-7 の3要素(重大性・ばく露・対象範囲)で優先度1〜3を付ける。
3. 各課題について、**観察された事実に直接対応する**改善策を、「すぐできる改善」と「検討を要する改善」に分けて書く。
4. 担当・期限・実施負担・効果確認の指標・再評価時期を企業と相談して埋める(担当と期限は企業が決定する。評価者は案を示す)。

**実施負担の目安(この評価表での区分)**

### 5-3. 改善策の書き方の約束事

- 改善策は必ず「観察された事実」の原因に対応させる(例:「台車が使われない」→原因「保管場所が遠い」→策「保管場所の移動」)。「意識を高める」「注意喚起する」だけの改善策は書かない。
- 改善の順番は、まず危険や負担の原因そのものをなくす・減らす(作業方法・配置・設備)、次に管理的な対策(ルール・ローテーション・教育)、最後に保護具の順で検討する。
- 効果確認の指標は、再訪問時に同じ方法で確認できるもの(観察回数、設備の台数、記録の件数、部門単位の集計)にする。個人の健康状態を指標にしない。
