### 3. 私たちが大切にしていること
**掲載本文**

  ケアマネの仕事では：本人・家族・地域の関係者をつなぎ、住み慣れた暮らしを支えます。

### 4. ケアマネジャーとして大切にしたい支援
**掲載本文**
「どのサービスを入れるか」の前に、「どう暮らしたいか」を一緒に考えます。
- **本人の言葉で聴く**：家族や専門職の意見だけで決めず、本人の望みを確かめます。言葉にしにくい方の思いも、表情や暮らし方から汲み取ります。
- **生活背景に目を向ける**：病状や身体の状態だけでなく、生活歴、役割、楽しみ、住まい、家族関係など、暮らし全体を理解します。
- **選択肢を示し、本人が選ぶ**：サービスや方法をメリットと負担も含めて分かりやすく伝え、本人と家族が納得して選べるよう支えます。
- **変化に合わせて見直す**：入退院や心身・家族の状況の変化に気づいたら、関係者と共有し、プランを柔軟に見直します。

**大切にしたい関わり方の例**：「もう一度、自分で買い物に行きたい」
- その言葉の背景（行きたい店、誰と行きたいか、不安なこと）を聴く
- 目標としてケアプランに書き、本人と共有する
- リハビリ、通所、福祉用具など複数の選択肢を一緒に検討する
- 実際に試した結果を確かめ、次の一歩を考える

**レイアウト**：左に2×2のカード（六角形アイコン付き）、右に淡いグリーンの「関わり方の例」カード。

**補足メモ**：右側は実際の事例ではなく、関わり方を説明するための例です。「これまでの支援で大切にしてきたことは何ですか」と聞くと、価値観の重なりやずれを確認しやすくなります。

### 5. 仕事内容
**掲載本文**
居宅のケアマネジャーとしての、一般的な業務の流れです。
1. **相談・契約**：本人や家族、医療機関などから相談を受け、説明と契約を行う
2. **アセスメント**：自宅を訪問し、心身の状態や暮らし、本人の思いを把握する
3. **ケアプラン作成**：望む暮らしを目標に、サービスの組み合わせを考える
4. **担当者会議**：本人・家族・事業者と話し合い、サービスを調整する
5. **モニタリング**：定期的に訪問し、サービスの状況や変化を確かめる
6. **見直し**：状態や希望の変化に合わせて、プランを見直す

⑥の後は②へ戻り、本人の暮らしに合わせて支援を続けていきます。
- **あわせて行う業務の例**：給付管理（毎月の実績確認など）、記録・書類作成、入退院時の医療機関との連携、地域包括支援センターなど関係機関との連携
- **実際の担当範囲［要確認］**：担当件数の目安、担当エリア、給付管理・請求業務の分担、訪問や記録の進め方は、面談で最新の内容をご説明します。

**レイアウト**：6つのステップを横一列（六角形アイコン＋番号）。下段に「あわせて行う業務」と「担当範囲［要確認］」の2枚のカード。

**補足メモ**：一般的な流れの紹介です。当事業所での担当件数や請求業務の分担は確認した事実だけを伝えます［要確認］。経験者にはこれまでの担当件数や進め方を聞き、違いを面談で確認し合いましょう。

### 9. これから一緒につくりたい職場
**掲載本文**

- **これから目指す姿**：まだ完成した形ではありません。働く一人ひとりの声を聞きながら、一緒につくっていきたい職場の姿です。
  1. 利用者だけでなく、働く職員の健康と幸せも大切にする
  2. 一人ひとりの専門性や自分らしさを生かす
  3. 困ったときに相談し、助け合える
  4. 現場の意見を生かし、より良い支援や働き方をつくる
  5. 自分で考え、仲間と協力して行動できる
- **私たちの考える「自律」**：一人ですべてを背負うことではなく、自分で考え、迷ったら相談し、仲間と協力して動くことです。
