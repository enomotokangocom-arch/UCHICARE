# 人と組織の幸せプロジェクト 企画書（案）

株式会社Uchi care が自社で実施する「人と組織の幸せプロジェクト」（12か月・Month 1〜12）の企画書です。

## 納品物（`output/`）

| ファイル | 内容 |
| --- | --- |
| `00_企画書_本文＋付録_一冊版.pdf` | 本文と付録をまとめた版（35ページ） |
| `01_企画書_本文.pdf` | 本文 24ページ（表紙・目次・参考文献を含む。年間計画の2ページはA4横） |
| `02_付録_記入用ワークシート.pdf` | 記入用ワークシート WS1〜WS10 と使い方（11ページ・A4縦）。印刷して手書きで使います |

## 編集可能な元データ（`src/`）

- `src/plan.html` … 本文の原稿（1ページ＝1つの `<section class="page">`）
- `src/worksheets.html` … ワークシートの原稿
- `src/style.css` … 色・文字サイズ・余白（`:root` の色を変えると全体に反映されます）

文章を直すときは、HTMLファイルをテキストエディタで開いて該当箇所を書き換え、下の手順でPDFを作り直してください。ページ番号と目次のページ数は自動で付きます。

## PDFの作り直し方

```bash
cd docs/happiness-project
npm install
node build.mjs   # output/ に PDF を出力
```

- Chromium が必要です。場所は環境変数 `CHROMIUM_PATH` で指定できます。
- 文章が増えてページからはみ出すと、`overflow` として該当ページが表示され、終了コードが1になります。
- 一冊版の結合には `python3` と `pypdf` を使います（無い場合は結合だけスキップされます）。
- フォントは Noto Sans JP と Zen Maru Gothic（npm の `@fontsource` パッケージ、SIL Open Font License）を埋め込んでいます。

## 使う前に確認すること

- 「要確認」「要決定」と書いてある箇所（一覧は本文16章）は、開始前に決めてください。
- 会社の理念、組織体制、職員数、予算、Uchi Well の商品仕様は資料として提供されていないため、記載していません。
- 予算・時間はすべて仮定に基づく試算です（本文15章に計算式があります）。
- 参考文献の※印のURLは、作成環境からリンク先ページを直接開いて確認できなかったものです。配布前にリンクを開いて確認してください。
