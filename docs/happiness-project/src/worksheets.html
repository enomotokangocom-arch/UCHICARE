付録　記入用ワークシート集（WS1〜WS10）

研修・月次振り返り・1on1で使うワークシートです。印刷して手書きで記入することを想定しています（A4・1シート1ページ）。

このシートは、あなた自身のためのものです。
  • 書く内容は自分で選べます。書かない欄があっても構いません。
  • 私生活やつらい経験を書く必要はありません。
  • シートは原則としてあなたが保管します。会社が回収・閲覧することはありません。
  • 会社に共有するのは、シート上で「共有してよい」とあなたがチェックした内容だけです。
  • 記入内容を人事評価に使うことはありません。
  • 記入例はすべて架空のものです。
