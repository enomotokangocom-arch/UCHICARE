## 1. 資料全体のコンセプト

### 中心メッセージ

> **助成金申請を入口に、顧問先の健康・定着・組織づくりまで支援する。**
> **社労士の専門性とUchi Wellの実行力を組み合わせ、顧問先の成果と社労士事務所の新しい収益を同時につくる。**

### ストーリーライン（見出しだけで読める流れ）

| 段階 | ページ | 読み手の心の動き |
|---|---|---|
| 共感 | P1〜P3 | 「顧問先の課題は見えている。でも、打ち手と収益化の手段がない」 |
| 解決策 | P4〜P7 | 「Uchi Wellと組めば、自分の専門性を活かしたまま提案の幅が広がる」 |
| 実務の具体性 | P8〜P11 | 「助成金の扱いも適法で、30日で試せて、自分の負担も少ない」 |
| 経済合理性 | P12〜P13 | 「報酬は業務の対価として筋が通っていて、積み上がる」 |
| 行動 | P14〜P16 | 「まず顧問先1社で試してみよう」 |

### トーン＆マナーの原則

- 社労士は「紹介者」ではなく **顧問先を共に支援する専門家パートナー**。
- 主役は **顧問先の経営改善**。助成金は「導入手段の一つ」、報酬は「業務の対価」。
- 「紹介してください」ではなく **「顧問先への提案価値を一緒につくる」**。
- 社労士が顧問先に **そのまま説明できる言葉** で書く。

### P2　社労士事務所が直面している課題

**見出し**
## 顧問先の課題は見えている。けれど、次の一手が出せない。

**リード**
毎月の手続きや相談を通じて、顧問先の変化に一番早く気づくのは社労士の先生方です。
それなのに、こんなもどかしさを感じていませんか。

**本文（6つの「あるある」カード）**

1. **顧問料が「比べられる」ようになった**
   手続き中心の業務は、価格で比較されやすくなっています。
2. **助成金申請が、その場限りで終わってしまう**
   申請が終わると、次の提案につながらない。
3. **顧問先に持っていける「新しい提案」が少ない**
   毎年同じ話になり、関係が“手続き窓口”に固定されがち。
4. **健康経営を相談されても、実行までは手が回らない**
   制度の話はできても、施策の企画・運営・効果測定までは難しい。
5. **離職や休職の兆しに気づいても、打ち手を渡せない**
   退職手続き・休職手続きで終わってしまう悔しさ。
6. **人は増やさずに、新しい収益の柱をつくりたい**
   新サービスを始めたいが、採用・育成の余力はない。

**キーメッセージ（ページ下部）**
→ その「気づき」を、顧問先の改善と事務所の新しい価値に変える方法があります。

### P3　顧問先企業が抱えている見えない損失

**見出し**
## 離職・休職・生産性低下は、「健康の問題」ではなく「経営の損失」です。

**リード**
顧問先の多くは、目に見えるコスト（給与・社会保険料）は管理していても、
目に見えない損失には気づけていません。

**本文（左：現象 → 右：経営への影響）**

| 顧問先で起きていること | 経営への影響 |
|---|---|
| 採用しても人が定着しない | 採用費・教育コストが回収できない |
| メンタル不調や休職が発生する | 残された社員の負担増 → 連鎖離職のリスク |
| 欠勤や「出勤しているが不調」（プレゼンティーイズム）が続く | 気づかないうちに生産性が下がる |
| 管理職が部下の不調に気づけない | 問題が表面化した時には手遅れになりやすい |
| 健康施策をやっても成果が見えない | 経営者が「効果がない」と判断し、施策が止まる |
| 健康経営優良法人を取得して終わっている | 認定が採用・定着の成果につながっていない |

**キーメッセージ**
→ 顧問先に必要なのは「健康イベント」ではなく、**損失を見える化し、減らしていく仕組み**です。
→ そしてこの損失に最初に気づけるのは、労務の現場に立つ社労士です。

> 注：数値（離職率・休職日数・損失額等）を掲載する場合は、出典（公的統計・調査）を明記すること。出典未確認の数値は掲載しない。

### P4　Uchi Wellとは

**見出し**
## Uchi Wellは、組織の健康課題を可視化し、経営改善につなげる伴走型サービスです。

**リード**
福利厚生でも、単発の健康イベントでもありません。
看護師・リハビリ専門職などの医療福祉専門職が、課題の発見から改善・効果測定まで伴走します。

**本文（「従来の健康施策」との比較）**

| | よくある健康施策 | Uchi Well |
|---|---|---|
| 起点 | 「何かやらなければ」 | データで見えた **自社の優先課題** |
| 内容 | セミナー・イベント単発 | 課題に合わせた **改善計画と実行支援** |
| 担い手 | 人事担当者が手探りで | **医療福祉専門職** が企画・実行を支援 |
| 経営者への報告 | 参加人数の報告 | **ダッシュボード** で進捗と変化を確認 |
| 成果 | 見えにくい | **改善前後の効果測定** |
| 期間 | 年1回 | **継続的な改善サイクル** |

**主な提供内容**
- 従業員アンケート・各種データによる組織課題の可視化
  （例：職場環境・エルゴノミクス評価、簡易ストレスチェック、腰痛リスク、介護と仕事の両立リスク など）
- 健康課題・メンタルヘルス・離職リスク・組織課題の分析と優先順位づけ
- 改善計画の策定と、医療福祉専門職による施策の提案・実行支援
- 経営者・人事担当者向けダッシュボード、施策の進捗管理
- 健康経営優良法人の認定取得に向けた伴走支援

**運営会社について（小枠）**
株式会社Uchi care ── 看護師・リハビリ専門職などの医療福祉専門職を有し、訪問看護・居宅介護支援・地域コミュニティ事業を展開。
Mission：医療福祉の力で健康と幸せを創造する
Vision：すべての人が自分らしくいられる共生社会を創る

**キーメッセージ**
→ 「健康づくり」を、**経営者が意思決定できる経営改善のテーマ** に変えます。

### P5　Uchi Wellが解決する範囲

**見出し**
## 「測って終わり」「イベントで終わり」にしない、6つのステップ。

**本文（循環図）**

1. **可視化** ── 従業員アンケートとデータで、健康・組織の状態を把握
2. **優先順位決定** ── 離職・休職・生産性に影響の大きい課題から特定
3. **改善計画** ── 目標・施策・スケジュールを経営者と合意
4. **施策実行** ── 医療福祉専門職が研修・面談・職場改善などを支援
5. **効果測定** ── 改善前後の変化をダッシュボードで確認
6. **継続改善** ── 結果をもとに次の計画へ（1に戻る）

**補足（図の下）**
社労士の先生方には、各ステップで **労務・制度面の視点** をいただくことで、
「現場の改善」と「制度の整備」が噛み合った支援になります。

**キーメッセージ**
→ 顧問先に **「やってよかった」と数字で説明できる** 健康経営へ。

### P6　なぜ社労士との連携なのか

**見出し**
## 課題に最初に気づくのは社労士。改善を動かすのがUchi Well。

**本文（4つの理由）**

1. **社労士は、企業の労務課題を最も早く把握できる**
   入退社・休職・勤怠・就業規則の相談を通じて、組織の変化をいち早く知る立場にあります。
2. **Uchi Wellは、健康・組織課題の分析と実行支援ができる**
   医療福祉専門職が、課題の分析から施策の実行・効果測定までを担います。
3. **組み合わせると、顧問先へ一気通貫の支援が届く**
   「制度・労務」と「健康・組織の改善」を、別々の業者ではなく一つのチームで。
4. **社労士の顧問契約を奪うものではなく、社労士の価値を高めるサービス**
   Uchi Wellは労務・社会保険・助成金申請の業務は行いません。顧問先との関係の中心は、これまでどおり先生方です。

**キーメッセージ**
→ 先生の「気づき」と、Uchi Wellの「実行力」。**一社では届かなかった支援** を顧問先へ。

### P7　三者メリット

**見出し**
## 顧問先・社労士事務所・Uchi Well、三者すべてに価値が残る仕組み。

**本文（表）**

| | 顧問先企業 | 社労士事務所 | Uchi Well |
|---|---|---|---|
| 得られる価値 | 離職防止・定着率の改善 | 提案力の向上（新しいメニュー） | 企業との接点の拡大 |
| | 健康課題・メンタル不調の改善 | 顧問先との関係強化（接点・相談の増加） | 社労士との長期的な地域連携 |
| | 生産性の向上 | 顧問料以外の新しい収益 | 労務面の専門家と組んだ質の高い支援 |
| | 健康経営の推進・認定取得の支援 | 他事務所との差別化 | 地域の健康づくりへの貢献 |
| ひとことで | **「人が辞めない、元気な会社」へ** | **「頼れる経営パートナー」へ** | **「地域の企業の健康を支える存在」へ** |

**キーメッセージ**
→ 誰かが我慢する仕組みではなく、**顧問先の成果を起点に、全員に価値が残る** 連携です。

### P8　助成金を活用した導入支援

**見出し**
## 助成金は「目的」ではなく、「導入を後押しする選択肢の一つ」。

**リード**
職場環境の改善や人材育成などの取り組みは、要件を満たす場合に国等の助成金の対象となり得ます。
活用の可否の確認と申請支援は、**社会保険労務士の先生方** が適法に行います。

**本文（流れ）**

1. **取り組み内容の整理**（Uchi Well・社労士）
   顧問先の課題と、実施予定の健康経営施策を整理
2. **活用可能性の確認**（社労士）
   最新の制度要件・申請時期・対象経費を確認
3. **申請手続きの順序確認**（社労士）
   計画届・交付申請等が **契約・発注・実施より前に必要な制度** があるため、順序を確認してから契約手続きへ
4. **申請支援**（社労士）
   書類作成・提出代行等は社労士が担当
5. **施策の提供**（Uchi Well）
   Uchi Wellは **健康経営施策の提供** を担当し、助成金の申請書類の作成・提出代行は行いません

**必ずお伝えしていること（注意書き枠）**
- 助成金の対象要件・申請時期・審査・受給可否は、企業ごとに異なります。**受給を保証するものではありません。**
- 制度は年度ごとに改正されます。制度名・助成額・要件は、その時点の公表情報で確認します。
- 助成金が利用できない場合も、Uchi Wellの支援内容・価値は変わりません。
- 助成金の支給決定を条件とした契約設計や、Uchi Wellから顧問先・関係者への金銭の還流（キャッシュバック等）は行いません。

**キーメッセージ**
→ 主役は顧問先の経営改善。助成金は **「使える場合に、正しく使う」** ものです。

> 【編集欄】候補となる制度（例：職場環境改善・人材育成・産業保健・両立支援等に関する制度）は、配布前に最新情報を確認し、制度名のみ・要件の要約とともに記載。助成額は原則として記載しない（記載する場合は「○年○月時点、詳細は公表資料参照」と明記）。

### P9　30日パイロット

**見出し**
## いきなり年間契約ではなく、まずは30日で確かめる。

**リード**
顧問先にとって一番のハードルは「本当に効果があるのか分からない」こと。
導入前診断（30日パイロット）で、自社の課題と支援の方向性を確認してから判断できます。

**本文**

**導入前診断（30日パイロット）**
**50,000円（税別）**

| 実施内容 | 顧問先が得られるもの |
|---|---|
| 従業員アンケート | 従業員の本音と健康状態の把握 |
| 健康・組織課題の分析 | 自社の課題が「感覚」から「データ」に |
| 離職リスク等の可視化 | どこに手を打つべきかが明確に |
| 経営者向け簡易レポート | 経営会議でそのまま使える資料 |
| 優先課題の整理・改善施策の提案 | 次に何をするかの具体案 |
| 導入効果の確認 | 年間契約を判断する材料 |

**安心ポイント（アイコン3つ）**
- 30日で完結、年間契約の義務なし
- 30日以内に年間契約へ移行した場合、診断料金を年間契約費用へ充当（※充当条件は契約書にて定めます）
- 診断結果は、社労士の先生との面談でも共有（顧問先の同意の範囲で）

**キーメッセージ**
→ 先生にとっても、**「まずは診断だけでも」と気軽に提案できる入口** です。

### P10　提携から導入までの流れ

**見出し**

### P12　提携報酬モデル

**見出し**
## 報酬は「紹介料」ではなく、「顧問先支援への対価」として設計します。

**リード**
提携報酬は、先生方が実際に行う **情報提供・初期ヒアリング・制度確認・導入後の労務フォロー・定例参加** などの業務に対する対価です。
名義貸しや、助成金の受給を条件とした成功報酬ではありません。

**報酬の対象となる業務（例）**
- 顧問先への情報提供、経営課題・労務課題の初期ヒアリング
- Uchi Wellへの適切な連携（課題の共有・初回相談の同席）
- 導入時の制度・就業規則等の確認
- 助成金活用可能性の確認 ※申請代行の報酬は顧問先と社労士の間の契約で別途
- 導入後の労務面での継続支援、定例ミーティングへの参加
- 顧問先との調整やフォロー

**3つのモデル（概要）**

| | ① 初回報酬型 | ② 継続報酬型 | ③ 初回＋継続報酬型（推奨） |
|---|---|---|---|
| 仕組み | 年間契約開始時に1回 | 契約継続中、毎月または毎年 | 導入時＋継続中の両方 |
| 金額例 | 導入1社当たり【○○円】 | 年間契約額の【○％】 または 月額【○○円】 | 導入時【○○円】＋年間契約額の【○％】 |

**推奨：③ 初回＋継続報酬型**
- 導入時の活動（ヒアリング・制度確認・調整）に対する対価が明確
- 導入後の継続支援（労務フォロー・定例参加）にもインセンティブが生まれる
- 「紹介して終わり」の関係にならない
- 社労士とUchi Wellが、長期的に顧問先を支援できる

**キーメッセージ**
→ 顧問先の支援が続くほど、先生の業務と価値も続く。**支援の実態と報酬が一致する** 設計です。

> 注：報酬の条件・支払時期・対象業務は業務提携契約書で定めます。顧問先への提携関係の開示方法も契約時に確認します。

## 7. 収益シミュレーション

### 前提条件（すべて仮置き・差し替え可能）

| 変数 | 記号 | 仮の値 |
|---|---|---|
| 年間契約額（1社当たり） | A | 【600,000円】（月額50,000円想定） |
| 初回報酬（1社当たり） | F | 【50,000円】 |
| 継続報酬率 | r | 【10％】（＝1社当たり年60,000円） |
| 年間の新規導入社数 | N | 3社 ／ 5社 ／ 10社 |
| 年間契約の継続率 | k | 【80％】 |

### 計算式

- 1社当たり継続報酬（年） ＝ A × r
- 当年の初回報酬 ＝ N × F
- 当年の継続中の社数：1年目 ＝ N、2年目 ＝ N ＋ N×k、3年目 ＝ N ＋ N×k ＋ N×k²
- **当年の提携報酬合計 ＝ N × F ＋ 継続中の社数 × A × r**

※ 契約開始月による按分は考慮しない簡易計算です（各年度の期首に契約開始と仮定）。
