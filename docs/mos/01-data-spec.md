## 1. GMOあおぞらネット銀行 明細（`8月GMO.xlsx`）

- 形式: xlsx、1シート。シート名は `statement-<数字>-<数字>-<数字>` 形式。
- 1行目がヘッダー:

| 列 | ヘッダー | 内容 | 正規化 |
|---|---|---|---|
| A | `日付` | `YYYYMMDD`（例 `20260831` の8桁） | `Date`（JST の日付） |
| B | `摘要` | 取引内容（全角・半角カナ混在） | NFKC 正規化 + 空白圧縮 |
| C | `入金金額` | 入金額。空欄＝入金なし | 整数（円） |
| D | `出金金額` | 出金額。空欄＝出金なし | 整数（円） |
| E | `残高` | 取引後残高 | 整数（円） |
| F | `メモ` | 担当者が手入力した用途メモ（任意、例: 家賃・駐車場代・会議費） | 文字列 |

- 並び順: 日付の **降順**。
- 摘要のパターン（確認したもの）:
  - `Visaデビット利用 <加盟店名> 承認番号：<数字> TID：<数字>` … デビットカード即時引落（1件＝1経費）
  - `Visaデビット利用　海外 <加盟店名> …` … 海外利用
  - `Visaデビット取消 …` / `Visaデビット取消（差額分） …` … 取消（入金側に計上される）
  - `振込 <金融機関> <受取人>` … 振込出金 / 振込入金
  - `振込手数料`
  - `AP(<収納代行名>` / `<カナ>(SMCC` … 口座振替
  - `普通預金 利息`
  - `振込 ＧＭＯアオゾラネツト　ＶＩＳＡデビツトキヤツシユバツク` … キャッシュバック（入金）
  - `振込 カ）ウチケア` … **自社名義口座からの入金（口座間振替）**
- 同日・同額・同摘要の行が複数存在しうる（例: 同日の `振込手数料` 100円が複数）。
  → 重複判定キーには **残高** を含める（同日同額でも残高が異なるため区別できる）。

## 2. 仙台銀行 明細（`8月仙台銀行.xlsx`）

- 形式: xlsx、1シート（過去分は同じ列構成の CSV `6月仙台銀行.csv` 等も Drive 上に存在）。
- 1行目がヘッダー:

| 列 | ヘッダー | 内容 | 正規化 |
|---|---|---|---|
| A | `照会口座` | `<支店名>（<店番>） <種別> <口座番号>` | 口座識別子（DBには末尾4桁のみ保存） |
| B | `番号` | 同一勘定日内の連番（1始まり） | 整数 |
| C | `勘定日` | `M/D/YYYY` 表示（Excel日付セルの可能性あり） | `Date` |
| D | `（起算日）` | 確認範囲では全て空欄 | 保存しない |
| E | `出金金額（円）` | 3桁カンマ区切り | 整数 |
| F | `入金金額（円）` | 3桁カンマ区切り | 整数 |
| G | `小切手区分` | 確認範囲では全て空欄 | 保存しない |
| H | `残高（円）` | 3桁カンマ区切り | 整数 |
| I | `取引区分` | `出金` / `入金` / `振込` | 文字列 |
| J | `明細区分` | 確認範囲では全て空欄 | 保存しない |
| K | `金融機関名` | 振込入金時の仕向金融機関（半角カナ） | 文字列 |
| L | `支店名` | 同上の支店 | 文字列 |
| M | `摘要` | 半角カナ（例 `ﾃﾞﾝｷ 8ｶﾞﾂﾌﾞﾝ`） | NFKC 正規化 |
| N | （ヘッダー空欄） | 一部の行のみ手入力メモあり | メモとして保存 |

- 並び順: 勘定日の **昇順**、同日内は `番号` 昇順。
- 摘要のパターン（確認したもの、分類ルールの根拠）:
  - `ATMﾌﾘｺﾐ` … 他口座への振込。**同日に GMO 側で同額の `振込 カ）ウチケア` 入金があり、口座間振替であることを確認**。
  - `ｷﾕｳﾌﾘｼｷﾝ` … 給与振込資金（総額。個人別ではない）
  - `ｾｲｻｸｺｳｺ(ｺｸ)` … 日本政策金融公庫への返済（元金・利息の内訳は明細に無い）
  - `ﾍﾝｻｲｷﾝ <n>ｶﾞﾂ` … 借入返済（元金）、`ｶﾘｲﾚﾘｿｸ` … 借入利息
  - `ｱﾒﾂｸｽ`、`JCB)…` … クレジットカード利用代金の引落（カード明細の合計）
  - `ﾄﾖﾀﾌｱｲﾅﾝｽ`、`ｾｿﾞﾝ)ﾘ-ｽ`、`MHF)…` … リース・割賦
  - `ｺｸｾﾞｲｼﾔﾎ` … 国税・社会保険料（源泉税等の預り金を含みうる）
  - `ZHｾﾞｲﾘｼﾎｳｼﾕｳ`、`PE ｾﾝﾀﾞｲｷﾀｾﾞｲﾑｼﾖ` … 税理士報酬・税務署
  - 入金: `ﾐﾔｷﾞｹﾝｺｸﾎﾚﾝ`（国保連＝介護・医療保険の報酬）、`ｶ)ｴｽ ｴﾑ ｴｽﾌｲﾅﾝｼﾔﾙｻ-ﾋﾞｽ`（ファクタリング入金）、
    `ｼﾖｸｷﾞﾖｳｱﾝﾃｲｷﾖｸ`（助成金）、`ｹﾂｻﾝﾘｿｸ`（預金利息）、個人名義の振込入金（利用者負担分等）
- 摘要に **個人名（カナ）** が含まれる行がある → 職員ロールには明細を表示しない。

## 3. 居宅売上管理表（`居宅売上管理表.xlsx`）

- 形式: xlsx、**1か月＝1シート** の帳票形式（表形式ではない）。ほかに `入力方法`（記入例）・`売上管理表`（空テンプレート）・`リスト`（サービスコード一覧）シートがある。
- 各月シートのレイアウト:
  - 1行目: `月間売上表`（左ブロック）、`年間売上表`（右ブロック）の見出し
  - 2行目: `令和N年M月`（対象年月）、`総売上` とその金額（左ブロック）、右ブロックにも `総売上`（年度累計）
  - 3行目: 見出し `単価` / `今月請求` / `月後れ請求` / `合計`（左）、`要介護` / `要支援` / `委託` / `合計`（右）
  - 4行目以降（左ブロック）: 区分小計行と明細行
    - 小計行: `要介護`、`要支援` … `今月件数, 今月金額, 月後れ件数, 月後れ金額, 合計件数, 合計金額` の6数値
    - 明細行: `居宅介護支援費`、`初回`、`加算/減算`、`介護予防支援費`、`委託連携`、`認定調査` 等 … 単価＋件数・金額
    - `委託` 行: `合計件数, 合計金額` の2数値のみ
  - 右ブロック: 1月〜12月の行に、要介護/要支援/委託の件数・金額と合計
- **レイアウトの版違いを確認**: 令和8年6月以降のシートは「月後れ請求」の前に「月後れ単価」列が1列追加されている。
  → 列位置固定ではなく **見出しラベルを起点** に読み取る。
- 検算関係（確認済）: `総売上 = 要介護合計 + 要支援合計 + 委託合計 (+ 認定調査合計)`。
  各小計行は `今月 + 月後れ = 合計`（件数・金額とも）。
- 試算表との関係（確認済）: 令和8年8月の `総売上` は、試算表「居宅支援」部門の `居宅介護事業収益` 8月度と一致。
  6・7月も一致。→ 居宅の売上は「管理表＝推計／請求額」「試算表＝確定」として照合できる。
- **データ品質上の注意（実ファイルで確認）**:
  - あるシートでは対象年月セルが `令和○年○月`（未入力のテンプレート文字列）のまま金額が入っている。
  - 9月分と思われるシートの対象年月セルが `令和8年8月` のまま（8月シートと年月が重複し、総売上が異なる）。
  - 右ブロック（年間表）の過去月の値が、後から作られたシートでは数円異なる（過去月の数値が書き換わっている）。
  → 取込時は **年月セルを唯一の根拠** とし、未入力・重複・検算不一致のシートは取込まずエラーログに記録する。
    シート名や他シートから年月を「推測」しない。過去の確定月の値が変わっている場合は上書きせず差分として保留する。
- 個人情報: 確認した範囲では利用者氏名等は含まれていない（件数・金額の集計のみ）。
- 対象外シート: `入力方法`（記入例。実在しうる数値が入っているため取込むと誤計上になる）・`リスト`（サービスコード一覧）は
  シート名で除外する（`KYOTAKU_NON_DATA_SHEETS`）。
- 利用者数: 居宅の利用者数は「今月請求件数（要介護＋要支援の今月件数）」で表示する（月後れ請求は前月以前の分のため除く）。

## 4. 残高試算表 年間推移・部門別（`株式会社Uchi care_残高試算表(年間推移)部門別含む.pdf`）

- 形式: テキスト埋め込み PDF（会計事務所作成）。5ページ。
- 各ページの先頭:
  - `令和 N年度 残 高 試 算 表 ( 年 間 推 移 ) <p> 頁`
  - 部門名: `事業所(合計)` / `訪問看護` / `居宅支援`
  - `損益計算書`、`単位： 円`
  - 列見出し: `勘 定 科 目 6月度 7月度 8月度 9月度 10月度 11月度 12月度 1月度 2月度 3月度 4月度 5月度 決算仕訳合計 当期合計`
- **会計年度は6月始まり**（令和8年度＝2026年6月〜2027年5月）。
- 明細行: `<勘定科目（文字間に空白あり）> <12か月分> <決算仕訳合計> <当期合計>`（14個の数値、マイナスは `-`）。
- 確認した勘定科目:
  - 売上: `訪問看護事業収益`、`居宅介護事業収益`、`返戻等`、`その他課税売上高`、`地域売上高`、`売上高合計`
  - 売上原価: `期首商品棚卸高` 〜 `売上原価`、`売上総損益金額`
  - 販管費: `役員報酬`、`給料手当`、`賞与`、`法定福利費`、`通勤手当`、`福利厚生費`、`教育訓練費`、`交際費`、`会議費`、
    `旅費交通費`、`通信費`、`消耗品費`、`修繕費`、`水道光熱費`、`新聞図書費`、`諸会費`、`ソフト利用料`、`支払手数料`、
    `車両費`、`地代家賃`、`リース料`、`保険料`、`租税公課`、`支払報酬料`、`減価償却費`、`雑費`、`販売管理費計`
  - `営業損益金額`
  - 営業外: `受取利息`、`雑収入`、`営業外収益合計`、`支払利息`、`売掛債権売却損`、`営業外費用合計`、`経常損益金額`
  - 特別: `固定資産売却益`、`特別利益合計`、`特別損失合計`、`税引前当期純損益金額`、`当期純損益金額`
- 検算関係（確認済）: `事業所(合計) = 訪問看護 + 居宅支援`（科目ごと）。`12か月 + 決算仕訳 = 当期合計`。
- 本部費の扱い: 試算表は2部門のみで「本部」部門は無い。役員報酬・支払報酬料等は `訪問看護` に計上されている。
  → 管理会計上は科目マスタで「本部費」を指定し、部門から抜き出して配賦し直す（`02-design.md` §4）。
- 未経過月: 9月度以降は全科目 `0`。**全科目が0の月は「未計上」とみなし保存しない**（0円の実績として保存しない）。
