# 訪問看護・居宅介護支援における腰痛予防研修（株式会社Uchi care 職員向け）

| ファイル | 内容 |
|---|---|
| `UchiCare_腰痛予防研修_訪問看護・居宅介護支援.pptx` | 編集可能なPowerPoint（16:9、25ページ、全ページに講師ノート） |

## 構成（30〜40分）

1. 表紙
2. 研修の位置づけと学習目標
3–5. 腰痛を理解するための基礎（構造、特異的／非特異的・急性／慢性、画像所見、多要因）
6–7. バイオメカニクス（モーメントアームの簡略モデル、作業条件の組み合わせ）
8–10. 訪問看護の場面別リスク（6場面を「負担が生じる理由→評価項目→対策を選ぶ根拠」で整理）
11–12. ノーリフティングと福祉用具（役割の違い、適応判断、用具・二人介助・ボディメカニクスの限界）
13–14. 居宅介護支援のエルゴノミクス（数値の根拠の種類を明示、一日の負担）
15–16. 慢性化を考える視点（恐怖回避モデル、睡眠・ストレス、運動の位置づけと限界）
17. 受診・医療相談が必要な腰痛
18–21. 事例検討（訪問看護1事例、居宅介護支援1事例、各解説）
22–23. 理解度確認（4問、正解の理由と誤答の問題点）
24. 重要事項の整理
25. 参考文献

## 編集時の注意

- フォントは「BIZ UDPゴシック」を指定しています（Windows 10以降に標準搭載）。ない環境では代替フォントで表示されます。
- 数値は、公的指針・ガイドラインの値、研究に基づく値、研修上の実践例のどれにあたるかを区別して記載しています。編集時もこの区別を保ってください。
- 図はすべて図形で描いた概念図です。写真を追加する場合は、住宅内のケアや面談・記録の場面を使い、利用者の尊厳とプライバシーに配慮してください。

## 再生成

```bash
NODE_PATH=/path/to/node_modules APPLY_THEME=/path/to/apply_theme.js ./src/build.sh
```

`APPLY_THEME` には、テーマの配色をPPTXに書き込む `applyTheme(file, THEME)` を公開するNodeモジュールを指定します（省略すると Office 標準の配色になります）。
